# Changelog

## v7.0.0

- Added an offline searchable palette browser: 1,707 SCI Figure Gallery references, six Seaborn palettes and 22 Scientific Colour Maps.
- Added statistical charts, for 19 total plot types: grouped/horizontal bars, error bars/bands, box/violin, histogram/KDE/ECDF, bubble, forest, hexbin, correlation, step and area plots.
- Expanded inputs to 22 extensions, including XLS/ODS, JSON/JSONL/NDJSON, NumPy, Parquet/Feather and HDF5.
- Preserved category text, literal NA labels and leading-zero identifiers in project snapshots and independent Python exports.
- Kept exported scripts limited to NumPy/Matplotlib, with separate discrete/continuous palette provenance and licenses.
- Improved palette window sizing, correlation-label contrast and Y-column selection synchronization.
- Added an import-ready Excel example and updated Chinese online, PDF and Word guides.
- Validated with 85 source tests; all input formats and plot exports exercised in the standalone EXE.

## v6.0.0

First GitHub release of Plota v6, with synthetic public examples and a complete Chinese user guide.

- Minimal Windows desktop interface with native drag-and-drop data import.
- Excel, delimited text and LAMMPS thermo output readers.
- Line/scatter plots, linear/quadratic fits, matrix heatmaps and filled contours.
- Multiple panels, row/column spans, shared/log axes and custom labels.
- Exact 16:9, 1:1, 4:3 or custom figure dimensions.
- Embedded SciencePlots presets with portable no-LaTeX rendering.
- Project snapshots and reproducible NumPy/Matplotlib-only Python exports.
- Tavotto-compatible main entry and static output names.
- Chinese Markdown, Word and PDF manuals, source build instructions and SHA256 release checksums.
