# Plota v7 新功能速查

适用于v7.0.0。请从本仓库Releases下载Plota.exe。

## 配色库

在“页面”点击“配色”按钮。窗口可按关键词搜索、按来源筛选，查看色块、HEX、图型设计解读和原始来源。选择后点击“用于线条与分类”或“用于连续色图”，即可应用；“随风格”恢复SciencePlots原有颜色。

1,735组配色由以下来源组成：

| 来源 | 数量 | 用法 |
| --- | --- | --- |
| SCI Figure Gallery | 1,707 | 图库记录的HEX或从缩略图提取的近似色；附设计笔记、论文来源和原图许可信息 |
| Seaborn | 6 | deep、muted、pastel、bright、dark、colorblind分类配色 |
| Scientific Colour Maps | 22 | batlow、vik、roma等连续/发散色图，适合数值热图与差异表达 |

取样色不代表论文作者原始绘图参数。应用“连续色图”只修改热力图、等高线、相关矩阵及六边形密度图；已画出的曲线分类颜色独立保留。选择连续色图后，新增矩阵图也会采用该色图。连续色图若用于分类曲线，会选取间隔较大的8个颜色，而不是相邻的256级色值。

软件内嵌配色与文字信息，不直接分发论文原图。原图可在SCI Figure Gallery上游仓库查看；本软件不附带整套论文图片。图库不包含所有论文的绘图源程序，因此本版将适用的方法独立实现为Matplotlib图型，不声称复现原论文的数据或分析。

## 19种图型

在“数据 → 类型”选择图型，再指定数据列并添加图层；“用法”按钮解释当前图型的数据要求。新增统计参数需要在添加之前选择，之后可选中图层修改相应列并在“样式”中应用。

| 图型 | 数据要求与说明 |
| --- | --- |
| 折线、散点 | 数值X/Y，可选线性或二次拟合 |
| 阶梯图 | 数值X/Y，按输入顺序绘制中点阶梯 |
| 面积图 | 数值X/Y，填充至零基线，不支持对数Y |
| 柱状图、横向柱状图 | X为分类或数值，Y为柱高/条长；多图层自动并排，同名分类跨文件对齐；误差列可选 |
| 误差棒 | 数值X/Y及非负X误差或Y误差，表示输入值±误差 |
| 误差带 | 数值X/Y及非负Y误差，按X排序绘制Y±误差阴影 |
| 气泡图 | 数值X/Y和非负“大小列”；面积与该列成正比，标记大小控制最大面积 |
| 直方图 | 使用Y样本列；样式中控制2–200个分箱，勾选“直方图归一化为密度”可显示概率密度 |
| 核密度 | 使用Y样本列；高斯核、Silverman经验带宽，需要至少两个不同样本值，不自动分组或剔除异常值 |
| 累计分布 | 使用Y样本列；经验累计概率由1/n递增到1，不拟合理论分布 |
| 箱线图 | 每个Y图层一组样本；中位数、四分位、1.5 IQR须线和离群值 |
| 小提琴图 | 每个Y图层一组样本；Matplotlib核密度形状及中位数，至少两个不同样本值 |
| 森林图 | X为效应值，Y为分类名称，X误差列为区间半宽；不会自动合并效应量 |
| 六边形密度 | 数值X/Y；颜色表示网格计数，分箱数控制网格密度 |
| 相关矩阵 | 自动选择数值列，按两列共同有限行计算Pearson r；常数列无有效相关值，不做显著性检验 |
| 矩阵热力图、矩阵等高线 | 二维等间距数值矩阵；范围0基且不含终止位置，色图和2–200等高线级数可调 |

误差棒、误差带和森林图使用你提供的误差数值，不自动计算置信区间。对数轴要求中心值与区间都处于正值范围。多个箱线/小提琴Y图层表示不同样本组；不会对数据按其他分类字段自动聚合。

## 22种文件扩展名

| 类型 | 扩展名 | 组织方式 |
| --- | --- | --- |
| Excel与ODS | .xlsx、.xlsm、.xls、.ods | 各非空工作表分别导入；宏不执行 |
| 文本表 | .csv、.txt、.tsv、.dat、.asc、.xy | 自动/手动分隔符，支持表头和跳过行；数值与分类文字列均保留 |
| GROMACS文本 | .xvg | 读取数值列，跳过#注释和@元数据；不解释XVG中的复杂多数据集控制语句 |
| LAMMPS thermo | .out、.log | 识别Step开头的数值表，沿用real时间换算和分段规则 |
| JSON | .json、.jsonl、.ndjson | 记录数组、等长列数组或columns/data表格；不是任意嵌套JSON解析器 |
| NumPy | .npy、.npz | 一维、二维或简单结构化数组；同长NPZ向量可以合并为多列，其他数组分开读取 |
| Arrow列式表 | .parquet、.feather | 读取为数据表，保留数值/分类列 |
| HDF5 | .h5、.hdf5 | 遍历普通一维/二维数值或定长字符串数据集；不是所有Pandas HDF存储布局的读取器 |

一维单数组增加Index索引列；二维数组使用Column_1等名称。NPY/NPZ不允许pickle对象；复数、高维数组需要你先明确所需分量或切片。HDF5中不支持的数据集会列入提示，不自动把高维数组压平。嵌套对象、自由文本或特殊二进制格式不因扩展名相同就保证可读取。

分类文字、NA类别名和前导零编号在项目快照及Python脚本中保留；数值测量列中的NA/NaN等空缺值保留为缺失。混合非数值内容可能使一列按分类处理，用于数值图前请核对和清理。LAMMPS .data仍不支持，原子坐标dump也不等于thermo表。

## 保存与导出

原有16:9、1:1、4:3、自定义画布、Science/IEEE/Nature/Bright/经典风格、项目保存、原生拖放和Tavotto入口均保留。

每个导出包仍包含PNG、PDF、SVG、plot.py、project.json及数据快照。新脚本支持分类文字，只需要NumPy和Matplotlib，不需要安装Seaborn、cmcrameri、pandas、PyArrow、h5py或Plota。使用第三方配色时，导出包附带配色来源与相应许可。运行脚本会覆盖同目录固定名称的三张图片；需要保留后期编辑时先另存。

在Tavotto中拖入plot.py，并选择完整导出目录。图库配色以实际色值存入配置，移到其他电脑后不依赖本地图库目录。输入兼容不等于通过某个期刊的投稿预检。

旧版纯数值项目可继续打开。v7分类数据快照增加列类型信息；旧版软件不保证能读取带分类文字的新项目。软件只支持明确列出的数值/统计图型，未加入地图投影、SHAP模型训练、桑基图或任意论文流程图生成。
